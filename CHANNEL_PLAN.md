# Looping Rube Goldberg — Channel Plan

**Brand:** Gentle Gentlemen · @gentle.gently.gentlish  

**Concept:** Soft chain-reaction / Rube Goldberg style animations that **reset themselves**. Calm, clever, faceless, built to loop.

**Platforms:** YouTube Shorts → Instagram Reels (same cut) → later long compilations.

---

## Positioning

| | |
|---|---|
| **Promise** | Soft machines that never finish — replay forever |
| **Feeling** | Whimsical + satisfying + relaxed |
| **Visual rule** | Objects only; gentle physics; no face |
| **Audio** | Soft taps / rolls; optional near-silent bed |
| **Loop rule** | Last beat restarts the first |

---

## Series (rotate)

1. **Desk Chain** — office objects cascade  
2. **Marble Run** — tracks that recirculate  
3. **Kitchen Table** — cozy domestic reactions  
4. **Soft Domino** — slow kind topples + reset  
5. **Loop Machine** — closed-system contraptions  

---

## Production

- Batch **21 prompts** weekly in Ghostcut  
- Animate in Blender / After Effects / AI video  
- Every export must **seamless-loop** (test 3×)  
- **3 Shorts/day** + same file to Reels  
- Sunday: stitch winners into a longer mix  

## Monetization order

YPP via Shorts/watch hours → IG as discovery → soft affiliates only after trust.
